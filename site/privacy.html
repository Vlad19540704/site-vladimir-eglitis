Контролёр персональных данных — Владимир Эглитис, консультант по алкогольной зависимости. По вопросам персональных данных: eglvlad2025@outlook.com.

Какие данные могут обрабатываться

Сам сайт не требует регистрации и не ведёт медицинских карт. При обычном просмотре сервер может технически обрабатывать IP-адрес, тип браузера, дату и время запроса и запрошенную страницу — это необходимо для работы и защиты сайта.

Если вы сами обращаетесь через электронную почту, мессенджер или чат, обрабатываются сведения, которые вы добровольно укажете: имя или ник, контактные данные, содержание сообщения и данные, необходимые для организации консультации.

Тема сайта связана с алкогольной зависимостью, поэтому сообщение пользователя может содержать сведения о здоровье. Такие сведения не запрашиваются без необходимости. Если вы добровольно сообщаете их в чате или переписке, они используются только для ответа на ваш запрос и оказания согласованной услуги.

Для чего используются данные

  • для ответа на обращение и связи с вами;
  • для согласования и проведения консультации;
  • для обеспечения безопасности и технической работы сайта;
  • для исполнения обязанностей, которые прямо требуются законом.

Правовые основания

Обычные контактные и организационные данные обрабатываются, когда это необходимо для ответа на ваш запрос, подготовки или исполнения договорённости о консультации, а также для законных интересов по обеспечению безопасности сайта.

Если в сообщении содержатся сведения о здоровье или иные специальные категории персональных данных, их обработка осуществляется только при наличии применимого правового основания; для чата на сайте используется отдельное явное согласие пользователя до отправки таких данных.

Передача третьим лицам

Для работы сайта и связи могут использоваться внешние сервисы: хостинг, электронная почта и выбранные пользователем мессенджеры. При подключении Jivo он используется как технический сервис чата и обработчик данных. Каждый внешний сервис обрабатывает данные по собственным условиям и политике конфиденциальности.

Данные не продаются и не передаются рекламодателям как база клиентов.

Срок хранения

Технические журналы сервера хранятся только столько, сколько необходимо для безопасности и диагностики. Переписка и организационные данные не хранятся дольше, чем это необходимо для ответа, консультации, урегулирования возможных вопросов и выполнения обязательных требований закона.

Ваши права

В пределах применимого законодательства вы можете запросить доступ, исправление или удаление данных, ограничение обработки, возразить против обработки, получить данные в переносимом формате и отозвать ранее данное согласие. Для этого напишите на eglvlad2025@outlook.com.

Важно

Не отправляйте через сайт сведения, которые не нужны для вашего вопроса. Для экстренной медицинской помощи, тяжёлого состояния отмены алкоголя, судорог, спутанности сознания или непосредственной угрозы жизни следует обращаться в местные экстренные медицинские службы, а не ждать ответа через сайт.
