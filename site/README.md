# Сайт консультанта — точный первый экран v0.4

Главная использует целиком утверждённое изображение «тёплый кабинет честного разговора.png», без обрезки, перекомпоновки и повторной генерации. Его SHA-256 совпадает с исходным утверждённым файлом.

Навигация, две кнопки записи и четыре пункта нижней полосы реализованы настоящими HTML-ссылками поверх соответствующих областей изображения. Все остальные страницы и статьи сохранены из v0.3. На узких экранах изображение целиком масштабируется по ширине, а рабочая навигация и кнопка записи дополнительно выводятся отдельными доступными HTML-элементами.

Важно: надписи, нарисованные внутри исходного изображения, являются частью растра. Их нельзя редактировать как обычный текст без отдельной подготовки чистого фона и HTML-слоёв. Текущий вариант выбран именно ради точного совпадения с утверждённым изображением. Дальнейшее изменение текста требует обновления изображения либо отдельной реконструкции слоёв.

Для просмотра распакуйте ZIP и откройте index.html. Отдельный HTML-превью содержит изображение, CSS и JavaScript внутри одного файла. Никакие реальные контакты, платежи, CMS или backend бота не подключены. Перенос в Tilda ещё не выполнен. Не публиковать до утверждения текстов и настройки обработки данных.

Проверены: побайтовое совпадение изображения, отсутствие старой шапки над ним, локальные ссылки, синтаксис JavaScript, рендер на 1672/1440/390/320 px и мобильное меню.
