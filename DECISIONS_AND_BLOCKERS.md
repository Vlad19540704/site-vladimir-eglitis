# Зафиксированные решения и реальные блокеры

## Решено Владимиром
- Визуал: `APPROVED_REFERENCE/visual_approved.png` — единственный утверждённый образец. Тёплый табачно-оливковый, светло-песочный, мягкие прямоугольники; без голубого и видео.
- Нет AI-портрета: только реальная фотография после ретуши. Пока — аккуратный placeholder.
- Нет цитат и блока «Опыт. Понимание. Реальная помощь», нет шаблонного «Разговоры о важном».
- Клиенты — только русскоязычные люди с алкогольной зависимостью. Онлайн, без заявленного обслуживания близких, без продвижения городов.
- Статьи: опубликованы после просмотра только 2 одобренные редакции; остальные v0.8 — ЧЕРНОВИКИ, не выпускать.
- Рубли и доступный способ оплаты для России важны, но юридический вопрос отложен. Не строить новый платёжный backend.
- Бесплатный Jivo для начального живого чата: принципиальное согласие на пробное подключение, НЕ разрешение собирать чувствительные данные или включать без политики.
- Отдельный VPS VDSina для сайта, не общий сервер с личной памятью.
- HTML+CSS+минимум JS. CMS на старте не нужна; статьи может добавлять Codex.

## Требует внешнего подтверждения
1. Реальная фотография Владимира (не приостанавливает локальную разработку).
2. Отдельный домен, его покупка и DNS. Владелец аккаунта — Владимир.
3. Реальные личные URL MAX, Telegram, WhatsApp/email. Ссылки старой версии могут быть неправильными. Заглушки не публиковать.
4. Окончательный текст страницы «Консультация», условия оказания, длительность, перенос, возврат, конфиденциальность.
5. Итоговый прайс в рублях, банк и законная схема получения оплаты — нельзя делать безусловные публичные заявления, пока не подтверждено.
6. Политика обработки персональных данных, совместимость Jivo с медицински чувствительной информацией, cookie/analytics.
7. Дата публикации каждой статьи, подтверждение квалификаций автора.
8. Покупка отдельного VPS и домена — только по явному разрешению.
9. Утвердить визуальное соответствие готового кода референсу по снятым скриншотам.

## Заведомо НЕ делаем
- Автоматическую оплату, CRM с данными о здоровье, собственную CMS, интеграции VK/Avito/Meta/MAX с ИИ, любые «анкетные» формы сбора медицинских сведений.
- Никакие изменения боевого сервера Лилы и работа с её личной памятью.
