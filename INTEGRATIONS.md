# Счётчики и Jivo — эксплуатация

## Google Analytics 4

Владелец принял условия 5 октября 2026. Аккаунт «Владимир Эглитис — eglitisonline.com», ресурс `557425867`, веб-поток `16046363015`, публичный ID `G-8S7ZD7FEB8`. Часовой пояс Finland / Europe/Helsinki, валюта EUR. Дополнительный обмен данными аккаунта выключен.

В кабинете настроены: Enhanced Measurement выключен; Google Signals не включён; User-ID и предоставленные пользователями данные не используются; подробные данные местоположения/устройства выключены; персонализация рекламы запрещена во всех 307 регионах. Хранение событий и пользователей — 2 месяца, сброс при новом действии выключен (Google применяет изменение хранения через 24 часа; агрегированные отчёты хранятся отдельно). Маскирование email включено; дополнительно настроено 20 потенциально личных параметров URL. Ссылки с рекламными идентификаторами не используются для атрибуции.

На сайте нет обращений к Google до согласия. Basic Consent Mode: analytics_storage разрешается только выбранным посетителем; три рекламных согласия всегда denied. Отказ равноправен разрешению, сохраняется 180 дней; смена выбора в подвале. Cookie GA ограничены 90 днями без продления. При отзыве cookies очищаются и документ перезагружается, освобождая загруженный SDK. Если localStorage недоступен, решение действует только в открытом документе.

События:

| Событие | Когда | Значение |
|---|---|---|
| `page_view` | Просмотр при разрешённой статистике | Страница из фиксированного списка, без query/hash; нейтральный заголовок |
| `contact_intent` | Нажатие внутренней ссылки на контакты | Интерес к связи, не заявка |
| `contact_click` | Нажатие Telegram / WhatsApp / MAX / email | Ключевое событие, один раз за сеанс, без денежной ценности; не подтверждение отправки сообщения |
| `chat_open_request` | Запрос загрузки одобренного Jivo | Вспомогательное событие, не сообщение и не консультация |

Параметры `contact_method` и `placement` зарегистрированы как измерения события «Способ связи» и «Место кнопки». Значения — перечисления, не контакты, тексты, диагнозы или адреса ссылок. Стандартные purchase/qualify_lead/close_convert_lead, созданные GA4 по бизнес-целям, сайт не отправляет. Их наличие не означает продажи.

Перед загрузкой SDK удаляются произвольные query/hash из адреса браузера. Источник перехода — только origin известных поисковиков/площадок из allowlist; частные домены и полный адрес реферера не передаются. Из UTM принимаются только эти значения:

- source: `telegram`, `whatsapp`, `max`, `google`, `bing`, `partner`;
- medium: `social`, `referral`, `cpc`, `email`;
- campaign: `launch_2026`, `articles_2026`, `partners_2026`.

Пример ссылки размещения: `https://eglitisonline.com/?utm_source=telegram&utm_medium=social&utm_campaign=launch_2026`. Не добавлять в UTM имя, диагноз или клиентские идентификаторы. Остальные значения отбрасываются. Это сознательное ограничение: атрибуция менее подробна, свободный текст не уходит в счётчик.

Статистика охватывает только согласившихся посетителей, без блокировки аналитики их браузером. Число кликов не равно числу клиентов. Реальные обращения и консультации вести отдельно без выгрузки персональных данных в GA4.

Связь доменного Search Console с GA4 создана 5 октября после подтверждения владельца в момент передачи поисковой статистики. Яндекс Вебмастер / Wordstat / Метрика остаются на паузе до отдельного решения владельца.

## Jivo

Владелец зарегистрировал аккаунт 5 октября 2026. Российская оферта от 26.03.2026, пункт 4.5, прямо запрещает обработку данных резидентов ЕС/ЕЭЗ. Поэтому действующий российский виджет не публикуется. Предыдущая регистрация и галочка посетителя не устраняют это ограничение. AGENTS.md также требует подтверждённого договора обработки данных.

С разрешения владельца отправлен запрос в поддержку Jivo через официальный чат: подходящий регион/аккаунт, DPA, трансграничные передачи, субобработчики, хранение/удаление, сведения о здоровье, бесплатный тариф; дополнительно запрошена совместимость Telegram и MAX. Ответ и договор ожидаются. Ничего платного не заказано. Демо Pro действует 14 дней; не строить рабочую конфигурацию на функциях, требующих оплаты после демо.

Подготовленный код чата остаётся выключенным. Сборка не даст включить widget ID без `jivo_dpa_confirmed: true` в локальном файле согласований. После подходящего договора требуется: назначить Владимира оператором, выставить русский язык и оливковое оформление, отключить активные приглашения, AI/ботов, звонки, рассылки и обязательный сбор телефона/email; проверить бесплатный режим, отдельное согласие перед загрузкой, приём и ответ в кабинете. Политику обновить под фактического обработчика и договор.

Telegram интеграция в Jivo требует бота через официальный @BotFather. Личный аккаунт по телефону мастер не подключает. MAX требует прошедшего модерацию бота из подтверждённого бизнес-профиля организации/ИП/самозанятого — резидента РФ. Владелец подтвердил отсутствие такого профиля; интеграция MAX в Jivo пока недоступна, прямой MAX на сайте сохраняется. Существующие личные ссылки сайта работают самостоятельно. Не подменять их ссылками на неподключённых ботов. Бот служит транспортом к человеку; собственный AI не создаётся.

5 октября владелец явно разрешил создать и настроить служебного Telegram-бота. Через официальный @BotFather создан `@eglitisonline_contact_bot`, имя «Владимир Эглитис — запись»; описание и краткая информация указывают, что подключение готовится, и направляют к действующим контактам сайта. Публичная карточка проверена. На сайте личная ссылка Telegram не заменяется ботом до проверки приёма и ответа через Jivo.

Токены ботов — секреты. Вставлять только в штатную форму Jivo после требуемого подтверждения новых прав, не читать в лог, Git, отчёт или исходники. Авторизацию, ввод/смену учётных ключей и принятие договоров выполняет владелец. Создание бота выполнено Codex после отдельного подтверждения владельца. Дальнейшую настройку и тесты выполняет Codex.

## Проверки и выпуск

- `scripts/test_service_consent.py`: изолированный браузер, фиктивные SDK, никаких запросов реальным поставщикам. Проверяет отказ, маскирование, отдельное согласие чата, отзыв после сбоя, preview/noindex, контрактные ограничения, клавиатуру и axe на 320/390/768/1440 px. Включён в GitHub CI.
- `scripts/audit_site.py`: обычная навигация после выбора «Без статистики»; специальные сценарии согласия проверяются отдельным тестом.
- `scripts/check_analytics_runtime.py --live`: одноразовый production браузер, технические события помечаются debug_mode; проверяет отсутствие запросов до согласия, реальные GA4 page_view/contact_click, очистку URL, отзыв и cookies. Никаких сообщений пользователям не отправляет. Сырые payload/client ID не сохраняются. Отчёт — игнорируемый `output/analytics-runtime.json`.
- ID в `services.public.json` публичные; `service_approval.json` игнорируется Git и содержит только фактические подтверждения договоров. Production deployment повторно строит артефакт, проверяя разрешения подключения; preview/staging не подключают внешние SDK.
- Выпуск: исходные тесты → commit/push → успешный CI → backup actual production → build → SHA-256 staging/production → публичная проверка. Никаких правок на сервере напрямую.
