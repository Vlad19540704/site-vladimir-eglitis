# Критерии приёмки (не «на глазок»)
- Содержимое `site/index.html` читабельно без JS. Заголовок/подзаголовок и путь записи видны на мобильном без навязчивого попапа.
- В навигации не более 5 главных пунктов после утверждения редакторской архитектуры.
- В публичной витрине ровно две утверждённые статьи; обе доступны со страницы `/articles.html`, ссылка с главной не ведёт на черновик.
- Статьи не редактированы смыслово; каждая — один h1, иерархия h2; корректный автор, медицинское примечание, ненавязчивый переход к консультации.
- Нет заявленной работы с родственниками/наркотиками, выдуманных регалий, ложного фото, эмоциональных обещаний, AI-клише.
- Изображения не тяжёлые/не битые, есть понятные alt. Минимальный контраст и читаемые шрифты в тёмных блоках.
- Реальные screenshots минимум 1440/768/390/320. Visual diff по утверждённому PNG с перечислением разрешённых отклонений.
- Меню открывается клавиатурой, tab-order понятен, focus виден, CTA нажимается и ведёт в подтверждённый контакт.
- Все внутренние ссылки существуют. Нет пустых `href=#`, `javascript:` и фальшивых персональных URL на боевом сайте.
- Stage закрыт от индексации. На production `noindex` снимается только при наличии домена, HTTPS, актуальных контактов, юридических материалов, sitemap, canonical и approval.
- Lighthouse mobile: зафиксировать LCP/CLS/INP (не заявлять результаты без измерения); не добавлять тяжёлые фреймворки.
- Не передавать содержание форм, диагнозы или тексты переписки в аналитику. Jivo подключать только после правовой проверки и согласованного режима.
- Backup и восстановление проверены на отдельном VPS, настроены TLS, SSH key-only, firewall, rollback. Не трогать сервер памяти Лилы.
