# Один пакет — автономная работа Codex

Отправьте Codex текст START_CODEX.txt или вставьте его содержимое первым сообщением. Codex сам должен достать архив (если у него есть доступ к этой беседе или к папке загрузок), распаковать, настроить рабочую среду и выполнить проект. Если по фактическим ограничениям он не может прочитать исходный архив, пользователь выполняет одно действие — скачивает ZIP в «Загрузки» или прикрепляет его к Codex; **ничего больше вручную делать не нужно**.

Приоритет инструкций: AUTONOMOUS_EXECUTION.md > AGENTS.md > CODEX_MASTER_TASK.md. Ограничения прошлого локального задания переопределены: после этапов тестирования Codex готовит и проводит заказ отдельного VPS, домена, настройку DNS/SSH и проверку деплоя с конкретными одобрениями покупок/публичного запуска.
