# Инструкции кодовому агенту
- Сайт принадлежит Владимиру. Не подменять утверждённый дизайн «улучшенным». Запрещены типовые AI-градиенты, клише, три карточки ради трёх карточек, нумерованные маркетинговые шаги, выдуманный портрет и видео.
- Главная аудитория: только русскоязычные люди с алкогольной зависимостью; НЕ заявлять консультации родственников, работу с наркотической зависимостью или медицинское лечение.
- Основной формат: онлайн. Не продвигать на главной Хельсинки, Ригу или очные встречи.
- Оплата в рублях/через Сбер на странице: утверждение, реальность и законность необходимо подтвердить перед публикацией. Платёжный backend сейчас не создавать.
- Только HTML/CSS/минимум JS. Не вводить Astro, React, WordPress, CMS без отдельного решения.
- Не менять утверждённый авторский текст двух статей — только вёрстка, SEO-метаданные и технические элементы.
- Jivo: только подключение после подтверждённого договора по персональным данным и явного согласия клиента; без собственного AI и без передачи чувствительных данных в аналитику.
- Stage/production: сохранять noindex на staging; убрать на утверждённом production только после проверки домена и всех политик; не публиковать черновики.
- Никогда не открывать/не коммитить токены, IP SSH, пароли, банковские реквизиты, персональные клиентские данные. Сначала локальный build+test, затем ревью. Доступ к серверу только после подтверждения.
- Отчёт после каждого этапа: список изменённых файлов, результат тестов, проблемы, скриншоты desktop/tablet/mobile, что требует решения Владимира.
- Постоянное правило владельца: все изменения сайта и инструментов выпуска фиксировать и отправлять в приватный GitHub до развёртывания. Staging и production разворачивать только из опубликованного в GitHub коммита; после каждого развёртывания сверять версию и хэши файлов сервера с артефактом этого коммита. Не править сайт непосредственно на сервере.
