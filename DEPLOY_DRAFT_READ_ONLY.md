# Черновик развёртывания (НЕ запускать до одобрения)
1. Зарегистрировать ОТДЕЛЬНЫЙ домен на Владимира. Выписать точный DNS.
2. Заказать ОТДЕЛЬНЫЙ VPS VDSina. Сверить текущие реальные RAM/disk/traffic и условия; начать с 1 GB/10 GB только если достаточно места ОС и логам.
3. Базовая установка: поддерживаемая ОС, SSH только по ключу, непривилегированный deploy, firewall 22/80/443, регулярные обновления, Caddy.
4. Статические файлы в /srv/consultant-site/current, отдельные права. Не класть в webroot исходные docx/zip, тесты, AGENTS.md, sitemap-template или .git.
5. Настроить TLS через Caddy на фактический домен, отдельно HTTP→HTTPS и выбор www/no-www.
6. CI/деплой: upload только после полного прохождения тестов и утверждения; сохранять релизы `releases/YYYYMMDD...` для rollback. Минимум одна внешняя ежедневная резервная копия + проверка восстановления.
7. Разделять staging и production. Staging закрыть Basic Auth и noindex; production only release gate.
8. Персональные ссылки MAX/TG/WhatsApp, контакты, условия и оплата — только проверенные. Не использовать `href` на главную страницу мессенджера вместо аккаунта.
9. После live: Яндекс Вебмастер, Google Search Console — владение подтверждает Владимир. Разместить sitemap.xml, canonical по реальному домену, проверить обход и лог ошибок.
10. Мониторинг: доступность сайта, истечение домена/сертификата, свободное место, ошибки 404/500, резервные копии, месячный короткий отчёт.
