# Автономный режим — обязательное дополнение (высший приоритет в пакете)

## Роли
Codex выполняет всю техническую, файловую, браузерную, операционную и тестовую работу самостоятельно в пределах доступных возможностей. Владимир выполняет логины/MFA, соглашается на списания и выбирает из небольшого числа реальных вариантов, когда архитектура/контент/цена требуют его решения. Не перекладывать на Владимира распаковку, копирование кода, установку ПО, ручную работу с терминалом, конфигурациями, DNS или SSH.

## Захват входных материалов
- Найти текущий ZIP в Downloads/Загрузки с доступом к локальным файлам; при наличии браузера можно попробовать открыть эту беседу ChatGPT и скачать последний пакет.
- В системах, где Codex не видит приватные файлы/вложения этого чата, запросить ровно одно действие: нажать «Скачать» или прикрепить архив в чат Codex. Дальше выполнить всё самостоятельно.
- Распаковать, сверить структуру, SHA256 и baseline, и создать отдельную рабочую копию. Зафиксировать исходное состояние в Git.
- Не делать вид, будто приватный sandbox:/ URL доступен Codex с другой сессии.

## Инструменты и setup
- Самостоятельно определить OS, shell, ограничения и доступность Computer Use / Browser Use. Использовать локальную рабочую папку, встроенный браузер или доступный Chrome.
- При установке пакетов/расширений, где необходим системный диалог, запросить у Владимира только подтверждение через интерфейс; установку и конфигурацию осуществить самостоятельно.
- Приватный GitHub repo проекта: предложить имя и создать через доступный браузер/CLI; если учетная запись закрыта — дождаться входа Владимира и продолжить самостоятельно.
- Playwright Chromium, HTML validation, Lighthouse, a11y basics, link/SEO checks. На десктопе и мобильных размерах сделать baseline и финальные скриншоты.
- Итерации: при каждом заметном визуальном расхождении сравнивать финальный сайт с APPROVED_REFERENCE/visual_approved.png, не менять утвержденную композицию самовольно.

## Сборка и содержание
- Первоисточник визуала — утвержденный скриншот, имеющийся в пакете, НЕ произвольный дизайн.
- Чистый статический HTML/CSS + необходимый JS, без новых сборщиков/CMS, если нет конкретной доказанной необходимости.
- Две утвержденные статьи и их тексты уже внесены; старые неподтвержденные статьи не публиковать.
- Главная: алкогольная зависимость, русскоязычные клиенты, онлайн; без «семейных консультаций», рекламных слоганов, AI-портретов и несогласованных городов.
- Подтвержденные реальная фотография, цены, контакты, юридические тексты и условия должны быть получены отдельно перед публикацией. При отсутствии — обозначить конкретный блокер, а не сочинять.
- Сайт должен быть полезен человеку с похмелья: простая навигация, ясная запись, читаемые шрифты, без продающих баннеров и длинных цепочек кликов.

## Автономные внешние действия
Разрешено без повторного согласования: открывать сайты поставщиков и документацию, сравнивать тарифы, готовить формы/корзины, устанавливать локальные бесплатные инструменты, создать отдельную папку и локальные файлы, тестировать, настроить новый проектный репозиторий при входе Владимира, подготовить конфигурации и предпросмотр.
Разрешено ПОСЛЕ конкретного подтверждения параметров: покупка VPS и домена, публичный запуск, изменение действующих записей DNS, включение стороннего виджета, размещение контактных данных/политик, выдача живых доступов к API.
Строго в пределах проекта: никакого изменения сервера памяти Лилы и не связанного с проектом ПО; отдельные аккаунты/ключи для нового VPS, историю проекта и backups держать вне нового VPS.
Одобрение покупок просить с конкретными ценой/периодом/поставщиком/автопродлением. Владимир выполняет платежное подтверждение лично, если оно требуется.

## DNS, VPS, SEO, виджет
- Выбрать конфигурацию отдельного VPS VDSina по актуальным данным; минимально 1GB/10GB при достаточности после аудита. Никакие IP/DNS/домен не подставлять по догадке.
- На НОВОМ VPS самостоятельно выполнить SSH, ОС, непривилегированный deploy, firewall, Caddy, HTTPS, backup + проверку восстановления, мониторинг, откат.
- После выбора домена самостоятельно подготовить и применить DNS, Search Console и Яндекс Вебмастер (пользователь авторизуется).
- Jivo: только начальный чат с живым оператором, отдельное подтверждение приватности, проверка доступности заявленных платформ; собственного AI сейчас нет.
- Российская оплата через сайт — отдельный будущий проектный этап; никаких скрытых платежей или фиктивных условий.

## Проверка качества и сдача
- Показывать реальный preview, скриншоты desktop/tablet/mobile и отчеты тестов; отдельно визуальное расхождение с макетом.
- Таблица решений: DONE (с доказательством), BLOCKED (одна точная причина), NEEDS USER (цена/варианты/действие).
- Доводить любой технически исполнимый этап до конца без запроса «что делать дальше?».
- Если компьютерное управление недоступно по региону, не симулировать его: перейти на файловый/терминальный/браузерный режим, попросить только минимальный ручной шаг при необходимости.
